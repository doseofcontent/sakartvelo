# Sakartvelo Skoniai, UAB - Website Interaction Design

## Core Interactive Components

### 1. Wine Catalog with Advanced Filtering (Parduotuvė)
- **Left Sidebar**: Multi-level filtering system
  - Wine Type: Red, White, Amber/Orange, Qvevri
  - Region: Kakheti, Kartli, Imereti, Racha-Lechkhumi
  - Price Range: Interactive slider (€10-€50+)
  - Sweetness Level: Dry, Semi-dry, Semi-sweet, Sweet
- **Main Grid**: Responsive wine card display (3-4 columns desktop, 1-2 mobile)
- **Wine Cards**: Hover effects revealing tasting notes, food pairings
- **Quick View Modal**: Detailed wine information without page navigation
- **Order Form**: Multi-step form with wine selection, quantity, contact details

### 2. Wine Tasting Booking System (Degustacija)
- **Calendar Interface**: Interactive date picker showing available slots
- **Time Slot Selection**: Morning/Evening options with capacity indicators
- **Package Selector**: Visual cards comparing 4-wine vs 8-wine experiences
- **Group Size Picker**: Dynamic pricing calculator
- **Booking Form**: Guest details, dietary restrictions, special requests
- **Confirmation System**: Email simulation with booking details

### 3. Georgian Cuisine Explorer (Meniu)
- **Category Tabs**: Appetizers, Main Dishes, Desserts, Beverages
- **Dish Cards**: Image galleries with ingredient highlights
- **Allergen Filter**: Dietary restriction toggles (vegetarian, gluten-free, etc.)
- **Wine Pairing Suggestions**: Each dish shows recommended wine pairings
- **Order Integration**: Direct links to wine shop for paired wines

### 4. Interactive Georgian Wine Map (Apie Mus)
- **Regional Map**: Clickable regions revealing wine characteristics
- **Timeline Slider**: 8,000-year winemaking history visualization
- **Qvevri Animation**: Interactive diagram of traditional winemaking process
- **Cultural Stories**: Expandable sections about Georgian wine traditions

## User Journey Flows

### Wine Discovery Flow
1. Land on homepage → Hero section with wine showcase
2. Browse featured wines → Filter by preferences
3. View wine details → Add to inquiry cart
4. Submit order form → Receive confirmation

### Experience Booking Flow
1. Learn about Georgian culture → Discover wine tasting option
2. Select tasting package → Choose date and time
3. Complete booking form → Receive confirmation email
4. Explore food menu → Plan complete experience

### Educational Journey
1. Read about 8,000-year history → Explore regional map
2. Learn about Qvevri method → Understand wine categories
3. Browse food pairings → Book tasting experience

## Mobile-First Interactions
- Touch-friendly filter toggles
- Swipeable wine card carousels
- Collapsible navigation menu
- One-thumb booking form completion
- Quick call/email contact buttons

## Form Validation & Feedback
- Real-time field validation
- Progress indicators for multi-step forms
- Success animations for submissions
- Error states with helpful guidance
- Loading states for all interactions

## Accessibility Features
- Keyboard navigation support
- Screen reader compatible labels
- High contrast mode toggle
- Font size adjustment controls
- Alternative text for all images
